## 技能与生成器

- skill-creator `quick_validate.py` 通过；主脚本与地图脚本均通过 `node --check`。
- 输出 JSON 与样例一致，地图样式/脚本全部内嵌，无遗留占位符。
- 生成器检查地图覆盖全部天数、坐标范围、浏览器配置；`verified-plan` 不允许缺少地图。
- 独立复核确认地图生命周期、延迟回调与生成资源无断链。修复非“决策点”命名时分支会消失的通用模板缺陷。
- 苏州未定日期 draft 样例仍可生成，6 栏目脚本执行无异常，预算 930 / 1,090 元；地图未配置明确标待补充。

## 数据与实现边界

HTML 的应用脚本、样式、图标、插画、坐标和预计算路线内嵌。地图首次打开才联网加载高德 SDK；断网会明确提示，并保留完整路线资料，不将文字资料冒称为地图已验收。地点外链按[高德 URI 官方文档](https://developer.amap.com/api/uri-api/guide/search/search)使用关键词和城市参数。

## 技能与展示案例解耦

技能下载包只包含通用页面模板、地图模块、空白数据骨架、生成器与合同。完整杭州数据移到 `examples/hangzhou.json`，仅由 Pages 构建脚本显式读取；没有城市、日期、坐标、电话、价格或地图 Key 的默认案例回退。技能入口不要求复制展示案例。

地图中心使用传入地点，备选名称和预算冲突提示来自输入字段；不再硬编码西湖中心、杭州备选或西溪/66卡规则。杭州案例将这些配置写入自身 JSON，因此展示功能保持。
