## 技能与生成器

- skill-creator `quick_validate.py` 通过；主脚本与地图脚本均通过 `node --check`。
- 输出 JSON 与样例一致，地图样式/脚本全部内嵌，无遗留占位符。
- 生成器检查地图覆盖全部天数、坐标范围、浏览器配置；`verified-plan` 不允许缺少地图。
- 独立复核确认地图生命周期、延迟回调与生成资源无断链。修复非“决策点”命名时分支会消失的通用模板缺陷。
- 苏州未定日期 draft 样例仍可生成，6 栏目脚本执行无异常，预算 930 / 1,090 元；地图未配置明确标待补充。
