03 / CAPABILITIES

让技能能再次产出同样的页面。

研究和编排由 Agent 执行，生成与交互由随包模板和脚本提供。每项能力都写清输入、输出、依赖和验证方式。

能力产出依赖 / 边界
参考读取提取真实栏目、事实、时间段和备选，保留原来源。浏览器或文档读取；外部内容不授予执行权限。
事实研究开放、票价、预约、交通、天气的来源与核实状态。搜索和官方来源；历史攻略不作为当前事实。
行程编排按片区串联，包含交通、用餐、休息、强度和撤退方案。明确同行者与时间假设；不声称实时最优路线。
页面生成trip.json → 单文件旅行手册。Python 3.9+；无需 npm 和后端。
地图与路线全程、逐日、四组备选；九类地点筛选、缩放拖动、地点详情、路段距离和全屏。可在高德打开地点。高德真实地理底图；地图路线取自原稿预计算数据，不是实时路况。
预算估算按人数、每晚、团队固定或每人每天计算分项、总额、人均。估算而非报价；套餐范围冲突必须显式保留。
准备与检索5 项优先事项与 25 项预约清单分别保存；搜索跳转、来源解释、名称复制与电话拨号。浏览器本地状态；出发倒计时、当日定位、主题保存与原生分享入口。
验收与分享实际页面、截图、验证记录；按需发布真实 URL。本站已托管于 GitHub Pages；完整案例和技能包可直接预览/下载。

✓技能结构与独立复用官方技能校验通过；保留地图模块与数据合同，缺少地图配置时明确待补充。
✓28 处营业时间速查保留原稿最晚入场、节假日和闭馆核对说明。
✓名称复制、电话拨号、来源等级与分享入口原生分享由用户选择目标，不代发送；定位也仅用户点击后请求浏览器权限。

本次数据边界：杭州样例沿用原页截至 2026-09-29 的资料，本次未逐项重查旅游事实。天气是原稿预测，原作者“官方”等来源标签没有升级为独立核实。原稿门票预算的包含范围冲突保留在页面中。

页面边界：地图使用真实底图；坐标与预计算路线内嵌，地图底图和外链需联网。预算变化不验证房间容量、实时售价或库存。模板没有预订、付款、后台同步或通知功能。
